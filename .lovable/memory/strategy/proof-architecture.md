# Unified Proof Architecture

## Proof Categories

| Category | Assets | Weight |
|---|---|---|
| **Certification** | CertainTeed MSA, NC GC License, Insurance, Warranties | Hard proof — verifiable |
| **Reviews** | Google/Facebook 4.9★, named testimonials, project-specific quotes | Social proof — emotional |
| **Team Credibility** | Owner involvement, combined experience, in-house crews, named contacts | Human proof — relational |
| **Project Visuals** | Drone shots, detail closeups, before/after, completed exteriors | Visual proof — tangible |
| **Process Discipline** | Written scope, photo docs, daily updates, final walkthrough, warranty delivery | Operational proof — procedural |
| **Quality Messaging** | Brand values, craftsmanship statements, standards callouts | Narrative proof — philosophical |
| **Regional Authority** | 8 counties, elevation expertise, mountain weather specs, local community | Local proof — contextual |

## Proof Density Rules

1. **Every page** must contain at least 3 of the 7 proof categories
2. **No page** should try to carry all 7 heavily — distribute the weight
3. **CTAs** always have at least 1 proof signal adjacent (badge strip, review quote, or credential)
4. **Forms** always show trust sidebar + badges
5. **Dark sections** use gold-accent proof elements for visual hierarchy
6. **Mobile**: Proof signals stack vertically but never get hidden — they compress, not disappear

## Proof Signal Priority by Visitor Stage

| Stage | Primary Proof | Secondary |
|---|---|---|
| **Awareness** (homepage, first visit) | Project Visuals, Regional Authority | Certification |
| **Consideration** (service pages, division pages) | Process Discipline, Certification | Reviews |
| **Evaluation** (about, team, certifications) | Team Credibility, Quality Messaging | Certification |
| **Decision** (reviews, projects, quote form) | Reviews, Project Visuals | Process Discipline |
| **Conversion** (inspection form, contact) | Certification, Team Credibility | Reviews |
