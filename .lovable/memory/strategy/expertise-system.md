# Author & Expertise System

## Core Principle
Every piece of content must feel like it was written or reviewed by a real person with hands-on experience in Western North Carolina roofing and construction — not generated by a marketing agency.

---

## Author Profiles

### Required Fields
```typescript
interface AuthorProfile {
  name: string;              // "Jake Morrison"
  role: string;              // "Lead Roofing Estimator"
  slug: string;              // "jake-morrison"
  photo: string;             // Professional headshot — NOT stock
  yearsExperience: number;   // 12
  certifications: string[];  // ["GAF Master Elite Certified", "HAAG Certified Inspector"]
  specialties: string[];     // ["Metal roofing", "Storm damage assessment", "High-elevation installs"]
  localExpertise: string;    // "Based in Highlands. Has worked on 200+ roofs above 3,500 ft elevation."
  bio: string;               // 2-3 sentences, conversational, credential-rich
  articlesWritten?: number;  // auto-counted
}
```

## Reusable Modules

### 1. Author Byline Block (every article)
**Placement:** Below H1, above article body
```
┌─────────────────────────────────────────────┐
│ [Photo]  Written by Jake Morrison           │
│          Lead Roofing Estimator · 12 years  │
│          GAF Master Elite Certified         │
│          Published Oct 15, 2025 · 8 min read│
└─────────────────────────────────────────────┘
```
- Headshot: 48px circle, real photo
- Name links to author archive page
- Role + years in one line
- Top certification badge (1, not a list)
- Date + read time

### 2. Reviewed By Badge (authority articles)
**Placement:** Below byline on technical/claims/code articles
```
┌─────────────────────────────────────────────┐
│ ✓ Reviewed by [Name], [Credential]          │
│   [One-line expertise statement]            │
└─────────────────────────────────────────────┘
```
- Green checkmark icon
- Used when content involves insurance, building codes, material specs, or safety
- Adds E-E-A-T signal for Google

### 3. Expert Commentary Callout (inline)
**Placement:** Within article body, 1-2 per article max
```
┌─────────────────────────────────────────────┐
│ 💬 Expert Insight                           │
│                                             │
│ "At elevations above 3,500 feet, we always  │
│  recommend a minimum 30-pound synthetic     │
│  underlayment. The freeze-thaw cycles up    │
│  here are brutal on standard felt."         │
│                                             │
│  — Jake Morrison, Lead Estimator            │
│    12 years in WNC roofing                  │
└─────────────────────────────────────────────┘
```
- Styled as a quote card with subtle brand accent border
- Real quote from team member (or attributed as such)
- Adds voice, credibility, and personality to educational content
- Never more than 2 per article

### 4. Local Expertise Note (inline)
**Placement:** Within article body where WNC-specific advice appears
```
┌─────────────────────────────────────────────┐
│ 🏔️ WNC Note                                │
│                                             │
│ In Highlands and Cashiers, annual rainfall  │
│ exceeds 80 inches — nearly double the       │
│ national average. This makes proper         │
│ underlayment and flashing details critical. │
└─────────────────────────────────────────────┘
```
- Mountain icon
- Short, specific, data-driven
- Ties generic advice to local conditions
- Can appear 2-3 times per article

### 5. Author Bio Card (article footer)
**Placement:** After article body, before related articles
```
┌─────────────────────────────────────────────┐
│ About the Author                            │
│                                             │
│ [Large Photo]                               │
│ Jake Morrison                               │
│ Lead Roofing Estimator                      │
│                                             │
│ Jake has spent 12 years on WNC rooftops,    │
│ specializing in metal roofing and storm     │
│ damage assessment at high elevations. He's  │
│ GAF Master Elite certified and has          │
│ personally inspected over 2,000 roofs       │
│ across Macon, Jackson, and Transylvania     │
│ counties.                                   │
│                                             │
│ [View all articles by Jake →]               │
└─────────────────────────────────────────────┘
```
- Larger photo (80px)
- Full bio (2-3 sentences)
- Link to author archive
- Schema: Person + author relation

### 6. Editorial Trust Strip (article header area)
**Placement:** Near byline or as a subtle bar below hero
```
┌─────────────────────────────────────────────┐
│ ✓ Expert Written  ·  ✓ Locally Researched  │
│ ✓ Fact-Checked    ·  Updated Oct 2025      │
└─────────────────────────────────────────────┘
```
- Small, muted text
- Signals editorial rigor without being heavy-handed
- "Updated" date shown when articles are refreshed

### 7. Project Expert Commentary (project detail pages)
**Placement:** On project detail / case study pages
```
┌─────────────────────────────────────────────┐
│ Project Lead's Notes                        │
│                                             │
│ [Photo] Jake Morrison                       │
│                                             │
│ "This Highlands estate sat at 4,100 feet    │
│  with full southern exposure. We chose      │
│  standing seam metal for its snow-shedding  │
│  and UV resistance. The steep pitch         │
│  required custom safety rigging — our crew  │
│  spent 3 days just on prep."               │
│                                             │
│ Material: Standing Seam Metal               │
│ Duration: 12 days                           │
│ Elevation: 4,100 ft                         │
└─────────────────────────────────────────────┘
```

## Page-Level Application

| Page Type | Modules Used |
|---|---|
| Blog Article | Byline + Editorial Strip + Expert Commentary (1-2) + Local Note (2-3) + Bio Card + Reviewed By (if technical) |
| Material Guide | Byline + Reviewed By (manufacturer) + Expert Commentary + Local Note + Bio Card |
| Storm Article | Byline + Editorial Strip + Expert Commentary (urgent tone) + Local Note + Bio Card |
| Town Page | Local Expertise Note (woven into intro) + Team member serving area callout |
| Project Detail | Project Expert Commentary + crew attribution |
| FAQ Hub | Reviewed By badge per section + Expert Commentary in answers |
| About Page | Team expertise summary (aggregate years, certs, counties) |
| Resource Pages | Byline + Reviewed By + Editorial Strip |

## Design Direction

- **Photos:** Real team headshots only. Never stock photos. Consistent lighting/background.
- **Typography:** Author names in DM Sans semi-bold. Roles in regular weight. Quotes in italic with left border accent.
- **Colors:** Expert callout cards use `--muted` background with `--primary` left border. WNC notes use `--accent` left border.
- **Spacing:** Callout cards have generous padding (p-6) and subtle rounded corners.
- **Hover:** Author name links show underline on hover. Bio card has subtle elevation on hover.

## Anti-Patterns (Never Do)
1. Never publish without author attribution
2. Never use "Admin" or "Highlander Team" as author — always a named person
3. Never use stock headshots
4. Never put expert quotes that sound corporate — they must sound like a real person talking
5. Never overload articles with callouts — max 2 expert + 3 local notes per article
6. Never use "reviewed by" for someone who didn't actually review the content
