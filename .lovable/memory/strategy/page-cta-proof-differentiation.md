## Layout Differentiation (Current Section Orders)

- **Roofing**: Hero(image) → Trust Strip → Opening Statement → Philosophy(2col) → Services(grid) → Climate(cards) → Materials(accordion) → Process(6-step) → Why(6-cards) → Repair Bridge → Mid CTA → Gallery(editorial) → FAQs → Closing CTA
- **Construction**: Hero(image) → Opening Statement(centered) → Standards Transfer(2col+image) → Disciplines Bridge → Services(grid) → Philosophy(2x2) → WNC Relevance(dark) → Mid CTA → Projects(2x2 images) → Why(2x2 cards) → Objections → Process → Trust(8-pillar) → FAQs → Closing CTA
- **About**: Hero(dark/no image) → Team Photo(overlap) → Owner Quote(centered) → Brand Story(2col) → Timeline(alternating) → Values(3x2 cards) → Craftsmanship(dark 2col) → WNC Roots(3col centered) → Expansion(2col+cards) → Trust(dark stats) → Closing CTA(green)
- **Gallery**: Hero(dark/stats grid) → Spotlight(cinematic card) → Filter Bar(sticky) → Masonry Grid → Mid CTA(strip) → Process(4-card dark) → Closing CTA
- **Blog**: Hero(dark/seasonal panel) → Featured(hero+sidebar) → Categories(tile grid) → Storm/Local(2col) → All Articles(filterable) → Newsletter(dark) → Closing CTA
- **Contact**: Hero(dark/what happens next card) → Guided Concierge(3-step form+trust sidebar) → Closing CTA(dark)

All constants in `src/lib/cta-config.ts`.
