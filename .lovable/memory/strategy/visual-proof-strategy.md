# Visual Proof Strategy

## Photography Categories & Direction

### 1. Drone / Aerial Shots
- **Purpose:** Scale, completion, neighborhood context, elevation drama
- **Direction:** Golden hour preferred. Show full roof from 45° angle, not straight down. Include surrounding mountains/trees for WNC context.
- **Use on:** Hero sections, project detail heroes, homepage FeaturedProjects, before/after "after" shots, service page headers

### 2. Detail / Craftsmanship Closeups
- **Purpose:** Prove quality — seams, fasteners, flashing, copper work, material texture
- **Direction:** Shallow depth of field. Clean hands/gloves in frame when showing active work. No clutter.
- **Use on:** Materials sections, process steps, trust cards, about page craftsmanship statements, project detail "scope of work"

### 3. Material Closeups
- **Purpose:** Show premium materials before installation — shingle bundles, metal panels, cedar shakes, copper sheets
- **Direction:** Studio-quality or clean jobsite staging. Include manufacturer labels when relevant. Natural light.
- **Use on:** RoofingMaterials component, service pages, project detail materials section, estimator tool

### 4. Team Imagery
- **Purpose:** Humanize the brand. Show real people, not stock photos.
- **Direction:** Natural poses, on-site preferred over studio. Branded gear. Diverse roles (leadership, crew, office). Warm lighting.
- **Use on:** Team page, about page leadership section, homepage MeetTheTeam, quote flow trust sidebar

### 5. Jobsite / In-Progress
- **Purpose:** Prove process discipline — clean sites, organized materials, safety gear, tarped landscaping
- **Direction:** Show orderliness. Staged material areas. Crew working methodically. Tarped plants/furniture visible.
- **Use on:** Process sections (OurProcess), about page, project detail process highlights, service pages

### 6. Completed Home / Exterior
- **Purpose:** Show final results in real mountain settings — curb appeal, architectural harmony
- **Direction:** Eye-level or slightly elevated. Landscaping visible. Blue sky or atmospheric clouds. Seasonal variety.
- **Use on:** Homepage hero, project cards, gallery, service page heroes, before/after "after" images

### 7. Before State Documentation
- **Purpose:** Make transformation visceral — damage, age, wear, failure points
- **Direction:** Honest but not ugly. Show specific problems (granule loss, rust, rot) not just general disrepair.
- **Use on:** Before/after sliders, storm damage page, repair pages, project detail challenge section

## Reusable Content Modules

### PhotoProofStrip
- Horizontal scroll of 4-6 detail shots with captions
- Use below process sections to reinforce "we do this right"
- Captions: short, technical ("Ridge cap sealed with 3-course flashing")

### ProjectHeroImage
- Full-bleed hero with gradient overlay
- Always drone/aerial or completed exterior — never stock
- Location + elevation badge overlay

### TeamMomentCard
- Candid team photo + name/role
- Use on homepage, about, team pages
- Never formal headshots — always on-site or natural

### CraftsmanshipGallery
- 3-column masonry of detail shots
- Lightbox on click
- Use on about page, certifications page, project detail

### BeforeAfterPair
- Always include: what changed, why it mattered, Highlander difference
- Never show "before" without context — always explain the problem

### MaterialShowcase
- Large material photo + specs overlay
- Use on service pages and project detail materials section

## Page-Level Recommendations

| Page | Primary Image Types | Avoid |
|---|---|---|
| Homepage Hero | Completed home, drone, mountain setting | Stock photos, generic roofs |
| Homepage FeaturedProjects | Drone aerials, completed exteriors | Interior shots, blurry photos |
| Service Pages | Category-specific detail + completed work | Generic stock, clip art |
| About Page | Team candids, jobsite order, leadership | Corporate headshots, stock office |
| Team Page | Natural team photos, on-site, branded gear | Studio portraits, stock people |
| Project Detail | Hero aerial, process shots, detail closeups, before/after | Unrelated filler images |
| Gallery/Portfolio | Curated best-of across all categories | Everything — be selective |
| Quote/Inspection Form | Trust sidebar with team photo + credentials | No imagery (feels transactional) |
| Certifications | Badge/certificate scans + detail work proving standards | Just logos/badges alone |
| Reviews Page | Project photos paired with testimonials | No imagery (loses credibility) |

## Anti-Stock Rules
1. **Never** use stock photos of roofing crews, homes, or materials
2. **Never** use AI-generated images for project work or team
3. Placeholder images must be clearly marked as "Photo Coming Soon" with branded styling
4. Every project card must have a real project photo or be hidden
5. Team members without real photos get initials avatar, never stock headshots

## Photography Shot List (for future shoots)
1. 3 drone shots per completed project (45° angle, straight-on, wide context)
2. 5 detail shots per project (flashing, seam, material texture, fastener pattern, edge work)
3. 2 before shots per project (problem area closeup, full roof overview)
4. 1 team photo per crew member (on-site, natural light, branded gear)
5. 2 jobsite organization shots per project (staged materials, clean work area)
6. 1 completed exterior per project (eye-level, landscaping visible, good light)
