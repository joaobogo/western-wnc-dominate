# Internal Linking & Content Journey Strategy

## Core Principle
Every page is both a destination and a waypoint. No dead ends. Every click should either deepen trust or move closer to conversion.

---

## Journey Maps

### Journey 1: Blog Article → Service Page → Quote

```
Blog Article (education/tips)
  ├─ Inline CTA → Service Page (contextual)
  ├─ Sidebar link → Related Service Page
  ├─ "Learn more about [service]" → Service Page
  │
  └─ Service Page
       ├─ Process section → builds confidence
       ├─ Trust proof strip → Reviews, Certifications
       ├─ Project examples → Gallery/Project Detail
       └─ Primary CTA → Request Inspection / Schedule Consultation
```

**Rules:**
- Every blog article links to exactly 1 primary service page (in first 2 paragraphs)
- Service page link uses descriptive anchor: "residential roof replacement" not "learn more"
- Blog sidebar shows related service card with thumbnail + CTA

### Journey 2: Service Page → Deeper Resources → Conversion

```
Service Page (e.g., Roof Replacement)
  ├─ "How much does this cost?" → Planning article / Cost guide
  ├─ "What material should I choose?" → Material Guide
  ├─ "Is repair enough?" → Repair vs Replace Guide
  ├─ "See examples" → Gallery filtered to this service
  ├─ "Who does the work?" → Team Page
  ├─ "What's the process?" → Inline process section
  │
  └─ All paths reconverge at:
       └─ CTA: Request Inspection / Schedule Consultation
```

**Rules:**
- Every service page links to at least 2 supporting resource articles
- Every service page links to at least 1 project detail / gallery view
- Every service page links to at least 2 town pages ("We serve [Town]")
- Resource links appear naturally in content, not just in a sidebar

### Journey 3: Location Page → Project Proof → Service → Quote

```
Location Page (e.g., /service-areas/highlands-nc)
  ├─ "See our work in [Town]" → Project Detail (town-tagged)
  ├─ "Read reviews from [Town]" → Reviews filtered
  ├─ Service cards → Relevant service pages
  ├─ Blog articles → Town-tagged articles
  │
  └─ Project Detail
       ├─ "More [service] projects" → Gallery
       ├─ "Get this for your home" → Request Inspection
       └─ "Similar projects in [Town]" → Back to location page
```

**Rules:**
- Location pages link to 3+ service pages
- Location pages link to 2+ blog articles (town-tagged preferred)
- Location pages link to project details in that area (if available)
- Every project detail links back to its town page AND service page

### Journey 4: Storm Content → Emergency Response → Quote

```
Storm Center Hub
  ├─ "What happened" → Storm update article
  ├─ "Check your roof" → Damage assessment checklist
  ├─ "File a claim" → Insurance claims guide
  ├─ "Get help now" → Emergency CTA (phone prominent)
  │
  └─ Storm Article
       ├─ Inline CTA → Request Emergency Inspection
       ├─ "What to do next" → Storm Damage service page
       ├─ "Document for insurance" → Insurance guide article
       └─ "Prepare for next time" → Maintenance article
```

**Rules:**
- Storm content ALWAYS includes phone number CTA (828) 524-7773
- Storm articles link to Storm Damage service page within first 3 paragraphs
- Storm Center hub links to all storm articles + storm service page
- Post-storm content links to seasonal maintenance for retention

### Journey 5: Education Content → Trust Pages → Confidence → Quote

```
Educational Article (materials, education, tips)
  ├─ "Who wrote this?" → Author bio → Team Page
  ├─ "Can I trust this company?" → Certifications
  ├─ "What do others say?" → Reviews
  ├─ "Tell me about the company" → About
  │
  └─ Trust Pages (About / Team / Certs / Reviews)
       ├─ Cross-link between all trust pages
       ├─ "See our work" → Gallery / Projects
       └─ CTA → Request Inspection (earned trust)
```

**Rules:**
- Every educational article includes author attribution linking to Team page
- Articles mentioning credentials link to Certifications page
- Articles about choosing contractors link to About + Reviews
- Trust pages cross-link: About ↔ Team ↔ Certifications ↔ Reviews

## Link Placement Rules

### In-Content Links (highest SEO value)
- Place primary service link in first 2 paragraphs
- Place secondary links (town, related articles) in H2 sections
- Use descriptive anchors: "standing seam metal roofing in Highlands" not "click here"
- Maximum 1 link per 100 words to avoid over-optimization
- Vary anchor text — never use identical anchor for same target across articles

### Sidebar/Aside Links
- Related articles (2-3)
- Primary service card with CTA
- Town badge (if location-relevant)
- Trust strip (certifications, review count)

### Footer/Bottom Links
- Related articles grid (3)
- Category navigation
- "Next steps" CTA block
- Town-aware CTA when location is known

### Navigation Links
- Breadcrumbs on every interior page
- "You might also be interested in" sections
- "Back to [parent]" links on detail pages

|---|---|---|
| Blog Article | 5 | 1 service, 1 town, 2 related articles, 1 trust page |
| Service Page | 7 | 2 towns, 2 articles, 1 gallery/project, 1 trust page, 1 resource |
| Location Page | 6 | 3 services, 2 articles, 1 project/gallery |
| Project Detail | 4 | 1 service, 1 town, 1 gallery, 1 CTA |
| Storm Article | 5 | Storm service, Storm Center, 1 town, 1 insurance guide, phone CTA |
| Trust Page (About/Team/Certs/Reviews) | 4 | 2 other trust pages, 1 service, 1 CTA |
| FAQ Hub | 8+ | Links embedded in answers to relevant service/resource pages |
| Material Guide | 5 | 2 services, 1 project, 1 town, 1 related material |

## Content Cluster Architecture

### Cluster 1: Roofing Authority
```
Hub: Residential Roofing
  Spokes: Roof Replacement, Roof Repair, Storm Damage, Specialty Roofing
  Support: Material guides, education articles, cost articles
  Proof: Gallery, project details, reviews
```

### Cluster 2: Construction Authority
```
Hub: Construction Division
  Spokes: Home Additions, Renovations, Outdoor Living, Custom Construction
  Support: Planning articles, inspiration articles, cost articles
  Proof: Gallery, project details, reviews
```

### Cluster 3: Local Authority
```
Hub: Service Areas
  Spokes: Individual town pages
  Support: Town-tagged blog articles, local news
  Proof: Town-specific projects, local reviews
```

### Cluster 4: Storm Authority
```
Hub: Storm Center
  Spokes: Storm articles, seasonal prep guides
  Support: Insurance guides, damage checklists
  Proof: Emergency response examples, storm repair projects
```

### Cluster 5: Trust Authority
```
Hub: About
  Spokes: Team, Certifications, Reviews, Gallery
  Support: Company news articles, project spotlights
  Proof: Self-reinforcing — each page proves the others
```

## Cross-Cluster Linking

Clusters must link TO each other, not just within:

| From Cluster | To Cluster | Link Type |
|---|---|---|
| Roofing → Local | "We serve [Town]" on service pages |
| Local → Roofing | Service cards on town pages |
| Storm → Roofing | "Repair or replace?" decision links |
| Education → Trust | Author bios, credential mentions |
| Trust → Proof | "See our work" from About/Team |
| Construction → Local | Town-specific construction context |
| All → Conversion | Every cluster terminates at CTA |

## Conversion Reconvergence Points

No matter where a user enters, within 2-3 clicks they should reach ONE of:
1. **Request Inspection form** (roofing path)
2. **Schedule Consultation** (construction path)
3. **Call (828) 524-7773** (emergency/storm path)
4. **Quote flow** (ready-to-buy path)

### Reconvergence Rules:
- Every page has a primary CTA visible without scrolling past 2 sections
- Every page has a closing CTA block
- Mobile sticky CTA persists on all interior pages
- Storm content uses phone-first CTA
- Education content uses soft CTA ("Questions? We're happy to help")
- Proof content uses confident CTA ("Ready for results like this?")
