## Highlander Roofing & Construction — Western North Carolina

## I. CONVERSION STRATEGY

### Philosophy
Premium positioning converts through trust accumulation, not pressure. Every page earns attention before requesting action. The site replaces a salesperson — educating, proving, and inviting.

### Page Hierarchy by Conversion Priority
| Tier | Pages | Role | Primary CTA |
|------|-------|------|-------------|
| **T1: Conversion** | Quote flow, Request Inspection | Close | Submit form / Call |
| **T2: High Intent** | Service pages, Storm Damage, Commercial | Qualify + Route | "Schedule Free Assessment" |
| **T3: Local Intent** | Town pages, Service Areas | Localize + Convert | "Get a Quote in [Town]" |
| **T4: Trust Building** | Gallery, Reviews, About, Team, Certs | Build confidence | "See Our Work" → Service page |
| **T5: Education** | Blog, Guides, Calculators | Attract + Nurture | In-content CTA → Service page |
| **T6: Navigation** | Homepage, Division hubs | Route efficiently | Dual-path: Roofing / Construction |

### Conversion Sequence Per Page
```
1. Relevance confirmation (0-3s): "You're in the right place"
2. Credibility flash (3-5s): Trust strip — years, projects, rating
3. Value delivery (5-30s): Answer the question they came with
4. Visual proof (30-60s): Photos, before/after, project cards
5. Social proof (60-90s): Testimonials matched to context
6. Process clarity (90-120s): "Here's what happens next"
7. Conversion invitation (120s+): CTA with trust reinforcement
```

### User Segmentation
| Segment | Signals | Experience |
|---------|---------|------------|
| **Emergency** | Storm page, "repair" queries, mobile | Phone CTA prominent, fast path, urgency acknowledged |
| **Researcher** | Blog entry, multiple pages, desktop | Deep content, comparisons, proof-heavy, soft CTAs |
| **Ready Buyer** | Service page direct, quote page | Streamlined form, minimal friction, trust at submit |
| **Commercial** | Commercial page, B2B signals | Portfolio emphasis, scope capability, consultation CTA |
| **Local Curious** | Town page entry, "near me" queries | Local proof, local testimonial, town-specific CTA |

## II. CTA HIERARCHY

### CTA Tiers
| Tier | Label Pattern | Style | Placement |
|------|--------------|-------|-----------|
| **Primary** | "Schedule Free Assessment" / "Get Your Quote" | Solid gold/amber button, full width on mobile | Hero, end of page, sticky mobile bar |
| **Secondary** | "View Our Work" / "See [Service] Projects" | Outlined button, forest green | Mid-page, after proof sections |
| **Tertiary** | "Learn More →" / "Related: [Topic]" | Text link with arrow, subtle | In-content, sidebar, between sections |
| **Emergency** | "Call Now — 24hr Response" | Red/amber accent, phone icon | Storm pages, mobile sticky, header |

### CTA Timing Rules
- **Hero CTA**: Visible without scroll. Brief. No form — just route to action.
- **Mid-page CTA**: After proof element (testimonial, project photo, process step). Earned placement.
- **End-page CTA**: Full CTA block with trust line. "No obligation · Free assessment · 24hr response."
- **Sticky mobile CTA**: Appears after 25% scroll. Stays until form interaction.
- **Never**: Two primary CTAs in viewport simultaneously. Popup on page load. CTA before any value delivered.

### CTA Support Copy (by objection)
| Objection | Support Line |
|-----------|-------------|
| Cost anxiety | "Transparent pricing — no surprises, no hidden fees" |
| Trust gap | "500+ WNC projects · 4.9★ · GAF Master Elite" |
| Commitment fear | "No obligation — just honest answers about your roof" |
| Timeline worry | "Most projects completed in 1-3 days" |
| Quality doubt | "Backed by manufacturer warranties up to 50 years" |

## III. OBJECTION HANDLING SYSTEM

### Pre-Emptive Objection Architecture
Objections are handled BEFORE the user consciously forms them, through strategic content placement:

| Objection | Component | Placement | Tone |
|-----------|-----------|-----------|------|
| "Too expensive" | Transparent pricing context, financing mention | Service pages after scope description | "Investment in your home's protection" |
| "Can I trust them?" | Trust strip, certifications, years in business | Every page header area | Calm, credential-backed |
| "Will it disrupt my life?" | Process timeline, communication promise | Service pages, quote flow | "We respect your home and your time" |
| "Do I even need this?" | Assessment tools, educational content | Blog, calculators, chatbot | Helpful, diagnostic |
| "Are they right for MY project?" | Local project photos, testimonials from similar projects | Town pages, service pages | "We've done this in your neighborhood" |
| "What about weather/timing?" | WNC climate context, seasonal guidance | Blog, service pages | Expert, reassuring |
| "Insurance headaches?" | Insurance process explanation, documentation help | Storm damage page | "We handle the paperwork" |
| "Construction scope?" | Portfolio breadth, process clarity | Construction division pages | "From additions to full renovations" |

### Component Types for Objection Handling
1. **Trust bars**: Inline stat strips (years, projects, rating) — appear near CTAs
2. **Side notes**: Small italic callouts next to form fields ("We never share your info")
3. **FAQ modules**: Dual-purpose SEO + objection (see Section VI)
4. **Process blocks**: Step-by-step with timeline ("Day 1: Inspection → Day 2: Estimate → ...")
5. **Testimonial callouts**: Quote matched to specific objection context
6. **Visual proof**: Before/after, project photos, certification badges
7. **CTA support copy**: One-line reassurance below every primary CTA button

## IV. LOCAL SEO FRAMEWORK

### Service Area Architecture
```
/services/[service-slug]           → Service intent (ranks for "[service]")
/service-areas/                    → Regional hub (ranks for "WNC [service]")
/service-areas/[town-slug]         → Town intent (ranks for "[service] [town] NC")
```

### Town Page Targeting (Priority Order)
| Tier | Towns | Criteria |
|------|-------|----------|
| **T1: Home base** | Franklin, Sylva | Office locations, most projects |
| **T2: High value** | Highlands, Cashiers, Brevard, Waynesville | Affluent, high project value |
| **T3: Volume** | Bryson City, Cherokee, Cullowhee, Dillsboro | Consistent demand |
| **T4: Expansion** | Hendersonville, Maggie Valley, Murphy | Growth markets |

### Town Page Unique Content Requirements
Each town page MUST have ≥300 words of unique content including:
- Town-specific climate/elevation data (rainfall, snowfall, wind exposure)
- Local architecture styles and common roofing challenges
- At least 1 real project photo from that town/county
- At least 1 testimonial from that area
- 3-4 unique FAQ questions (never duplicated across towns)
- Local landmarks or neighborhoods referenced naturally

### Anti-Thin Content Rules
- No town page without a real local project photo
- No duplicate service descriptions across town pages (link to service page instead)
- No town page under 500 total words
- No town page without a unique meta description
- Every town page must link to: 2+ service pages, 1+ blog article, 1+ other town page, quote flow

### Google Business Profile Integration
- Primary categories: Roofing Contractor, General Contractor
- Service area: All targeted towns
- Posts: Weekly, matching blog content calendar
- Photos: Add project photos tagged by town monthly
- Reviews: Request reviews mentioning specific town names
- Q&A: Seed with FAQ content from town pages

## V. ON-PAGE SEO RULES

### Heading Structure
```
H1: One per page. Includes primary keyword + location if relevant.
    Service page: "Roof Replacement in Western North Carolina"
    Town page: "Expert Roofing in Franklin, NC"
    Blog: "[Descriptive Title] | Highlander Roofing"
    
H2: Section breaks. Include secondary keywords naturally.
H3: Subsections. Supporting details.
Never skip levels (H1 → H3).
```

### Content Depth Requirements
| Page Type | Min Words | Keyword Density | Internal Links | Images |
|-----------|-----------|----------------|----------------|--------|
| Service page | 1,200 | 1-2% primary | 4+ | 3+ |
| Town page | 500+ unique | 1-2% "[service] [town]" | 4+ | 2+ local |
| Blog article | 1,000 | Natural | 3+ | 2+ |
| Division hub | 800 | Broad | 6+ | 4+ |

### Meta Templates
```
Service: "[Service] in Western NC | Highlander Roofing — Free Assessment"
Town: "[Service] in [Town], NC | 500+ Projects · 4.9★ | Highlander"
Blog: "[Title] | Roofing & Construction Tips | Highlander"
```
- Title: ≤60 characters, keyword-front-loaded
- Description: ≤160 characters, includes trust signal + CTA hint

### Image Optimization for SEO
- Alt text: Descriptive, includes location. "Metal roof replacement on Franklin NC home"
- File names: Kebab-case with keywords. `metal-roof-franklin-nc.webp`
- Lazy load all below-fold images
- Serve WebP with JPEG fallback
- Include width/height attributes to prevent CLS

### Internal Linking Rules
- Every page links forward (toward higher-intent pages)
- Blog → Service page (descriptive anchor text, not "click here")
- Service page → Related services (lateral) + Quote flow (forward)
- Town page → Service pages (up) + Quote flow (forward)
- Proof pages → "Start a similar project" (forward)
- Maximum 2 clicks from any page to a conversion endpoint

## VII. MOBILE-FIRST EXPERIENCE PLAN

### Core Mobile Principles
1. **Thumb-zone priority**: Primary CTAs in bottom 40% of screen
2. **One-column everything**: No side-by-side below 768px
3. **Touch targets**: Minimum 44×44px, 8px spacing between tappable elements
4. **Font minimums**: Body 16px, H1 28px, H2 22px — never smaller
5. **Scroll momentum**: No scroll-jacking. Natural iOS/Android scroll feel.

### Component Mobile Adaptations
| Component | Desktop | Mobile |
|-----------|---------|--------|
| Hero | Full-bleed image + overlay text | Stacked: image top, text below, CTA full-width |
| Service grid | 3-column cards | Single column, swipeable carousel optional |
| Trust strip | Horizontal 4-stat bar | 2×2 grid |
| Project gallery | Grid with hover effects | Vertical stack, tap to expand |
| Before/after | Side-by-side slider | Stacked with swipe or vertical slider |
| Navigation | Horizontal mega-menu | Bottom sheet or slide-over panel |
| Forms | Multi-column possible | Single column, large inputs, visible labels |
| Testimonials | Cards with pagination | Vertical scroll, one at a time |
| FAQ | Accordion | Same, larger touch targets |
| Calculator/tools | Side panel results | Full-screen result overlay |
| Blog | Sidebar + content | Content only, related articles below |
| Footer | Multi-column | Stacked accordions for link groups |

### Sticky Mobile CTA Bar
- Appears after 25% page scroll
- Contains: Primary CTA button + phone icon
- Height: 56px max
- Respects safe area (notch/home indicator)
- Disappears on scroll-up to reduce obstruction
- Reappears on scroll-down pause

### Mobile Performance Targets
- First Contentful Paint: < 1.5s on 4G
- Largest Contentful Paint: < 2.5s
- Time to Interactive: < 3.5s
- Total page weight: < 800KB initial load
- No layout shift from lazy-loaded content

## VIII. PERFORMANCE ARCHITECTURE

### Core Web Vitals Targets
| Metric | Target | Strategy |
|--------|--------|----------|
| LCP | < 2.5s | Hero image preloaded, WebP, sized, CDN-served |
| FID/INP | < 100ms | No main-thread blocking > 50ms, defer non-critical JS |
| CLS | < 0.1 | All images have dimensions, fonts display:swap, no injected content |

### Image Strategy
| Category | Max Width | Format | Quality | Loading |
|----------|-----------|--------|---------|---------|
| Hero | 1920px | WebP | 80% | `eager`, preload |
| Project cards | 800px | WebP | 75% | `lazy` |
| Gallery thumbnails | 400px | WebP | 70% | `lazy` |
| Gallery full-size | 1600px | WebP | 85% | On-demand (lightbox) |
| Blog inline | 800px | WebP | 75% | `lazy` |
| Team portraits | 400px | WebP | 80% | `lazy` |
| Logos/icons | SVG | SVG | — | Inline or sprite |
| Background textures | CSS | SVG/CSS | — | Inline |

### Font Strategy
```css
/* Playfair Display: Headings only */
@font-face {
  font-family: 'Playfair Display';
  font-display: swap;
  /* Subset: Latin only, woff2 */
  /* Preload the 700 weight only */
}

/* DM Sans: Body */
@font-face {
  font-family: 'DM Sans';
  font-display: swap;
  /* Weights: 400, 500, 700 */
  /* Preload 400 only */
}
```
- Total font payload: < 80KB
- Preload only critical weights
- System font fallback stack defined

### Animation Performance Budget
| Context | Allowed | Restricted |
|---------|---------|-----------|
| Desktop, no reduced-motion | Full framer-motion, scroll reveals, parallax | No video autoplay above fold |
| Mobile | Opacity + translateY only, shorter durations | No parallax, no complex SVG animation |
| Reduced motion preference | Instant state changes, no animation | Everything animated |
| Slow device (< 4GB RAM) | Minimal opacity fades only | All scroll-triggered animation disabled |

### Code Splitting
```
Route-based splitting:
  / → Index bundle
  /services/* → Services bundle
  /service-areas/* → Towns bundle  
  /blog/* → Blog bundle
  /gallery → Gallery bundle
  /request-inspection → Quote bundle
  
Component-based splitting:
  - Chatbot: lazy loaded on idle
  - Calculator tools: lazy loaded on route
  - Lightbox: lazy loaded on trigger
  - Map: lazy loaded on viewport intersection
```

### Caching Strategy
| Asset | Cache Duration | Strategy |
|-------|---------------|----------|
| Static assets (JS/CSS) | 1 year | Content-hashed filenames |
| Images | 1 year | CDN with content-hash |
| Fonts | 1 year | Immutable |
| HTML | 5 minutes | Stale-while-revalidate |
| API responses | 1 minute | SWR pattern |

## IX. MEDIA OPTIMIZATION RULES

### Image Processing Pipeline
```
1. Source: High-res original (≥3000px, camera/drone)
2. Crop: Aspect ratio per placement (16:9 hero, 4:3 card, 1:1 thumbnail)
3. Resize: Generate responsive set (400, 800, 1200, 1920)
4. Compress: WebP at quality target per category
5. Name: kebab-case-descriptive-location.webp
6. Alt: "[Description] in [Town], NC — Highlander Roofing"
7. Serve: <picture> with srcset, sizes attribute, width/height set
```

### Image Categories & Specs
| Type | Aspect | Sizes Generated | Alt Text Pattern |
|------|--------|----------------|-----------------|
| Drone/aerial | 16:9 | 800, 1200, 1920 | "[Project type] aerial view in [Town] NC" |
| Before/after | 4:3 | 600, 1200 | "Before/after [service] in [Town] NC" |
| Material closeup | 1:1 | 400, 800 | "[Material name] roofing texture detail" |
| Team portrait | 3:4 | 400, 800 | "[Name], [Title] at Highlander" |
| Project card | 4:3 | 400, 800 | "[Service] project in [Town] NC" |

### Video Policy
- No autoplay video above fold
- Thumbnail + play button pattern for all video
- Video hosted externally (YouTube/Vimeo) with facade loading
- Max 1 video per page
- Always provide poster image

### Page Weight Targets
| Page Type | Initial Load | Total (all lazy) |
|-----------|-------------|-----------------|
| Homepage | < 800KB | < 2.5MB |
| Service page | < 600KB | < 1.5MB |
| Town page | < 500KB | < 1.2MB |
| Blog article | < 400KB | < 1MB |
| Gallery | < 600KB | < 4MB (lazy thumbnails) |
| Quote flow | < 300KB | < 500KB |

## X. ANALYTICS & TRACKING MODEL

### Conversion Event Tiers
**Tier 1 — Primary (Revenue-direct):**
- `quote_form_complete` — Form submitted
- `phone_call_click` — Click-to-call
- `chatbot_handoff` — Bot routes to form/call
- `schedule_consultation` — Booking completed

**Tier 2 — Micro-conversions (Intent signals):**
- `quote_form_start` — First field interaction
- `quote_step_advance` — Multi-step progress
- `chatbot_open` / `chatbot_message_sent`
- `tool_result_viewed` — Calculator/quiz result
- `lead_magnet_download`
- `service_cta_click`

**Tier 3 — Engagement (Quality indicators):**
- `project_gallery_view` / `project_detail_view`
- `before_after_interact`
- `blog_to_service_click`
- `scroll_depth_75`
- `time_on_page_60s`
- `pages_per_session_3`

### Event Payload
Every event includes: `page_path`, `page_type`, `division` (roofing/construction), `device_type`, `traffic_source`, `session_page_count`, `timestamp`, plus event-specific metadata.

### Attribution
- Multi-touch: Track full journey from first touch to conversion
- Store: landing page, referrer, UTM params, pages visited, time-to-convert
- Categorize: organic_search, local_search, direct, social, directory, paid_search

### Reporting Cadence
| Frequency | Focus |
|-----------|-------|
| Weekly | Lead volume, phone clicks, form completion rate, top converting pages |
| Monthly | Service demand mix, town page performance, blog→conversion paths, CTA testing, mobile completion rates |
| Quarterly | Content ROI, page hierarchy adjustments, CTA language rotation, town page expansion, tool iteration |

### Data → Decision Rules
- Low form completion → Reduce fields, add progress indicator, add trust at submit
- Blog traffic but no service clicks → Add in-content CTAs, strengthen internal links
- Town page traffic but no conversion → Add local photos, local testimonial, strengthen CTA
- Mobile conversion gap → Audit form with keyboard, check sticky CTA, test simplified form
- Tool usage but no leads → Gate detailed results behind email, add "email this estimate"

### Intent → Structure Alignment
| Search Intent | Page | Structure Priority | CTA |
|---------------|------|-------------------|-----|
| "[service] [town] NC" | Town page | Local proof first | "Get a Quote in [Town]" |
| "[service] cost" | Service page | Answer first, qualify second | "Get Your Custom Estimate" |
| "metal vs asphalt" | Blog | Educate thoroughly | "Not sure? We'll recommend" |
| "roof repair near me" | Service page | Urgency + fast contact | Phone CTA prominent |
| "best roofer WNC" | Homepage/About | Proof-heavy | "See Why Homeowners Choose Us" |
| "storm damage insurance" | Storm page | Process + documentation | "Emergency Assessment — We Handle Insurance" |

### Trust Layer Stack (Every SEO Page)
```
Layer 1 (0-3s):   Trust strip + location signal + design quality
Layer 2 (3-15s):  Service content matching search intent
Layer 3 (15-45s): Visual proof — project photos, before/after
Layer 4 (45-90s): Social proof — matched testimonials
Layer 5 (60-120s): Process proof — "what to expect"
Layer 6 (90s+):   Conversion invitation with trust reinforcement
```

### FAQ Dual-Purpose Design
Every FAQ simultaneously:
1. Targets a long-tail search query (SEO)
2. Resolves an emotional objection (CRO)
3. Gets FAQPage JSON-LD markup (SERP features)
4. Links to relevant service/proof page (internal linking)

### Internal Linking = Conversion Funnel
```
LOW INTENT → → → → → → → → → → HIGH INTENT
Blog → Service Page → Town Page → Quote Flow
  ↑         ↑              ↑           ↑
Gallery   Reviews      Projects   Confirmation
```
Every page has ≥1 forward link toward higher-intent action.
Every journey reconverges on: quote form, phone call, or chatbot handoff.
Maximum 2 clicks from any page to a conversion endpoint.
