# Local SEO Strategy — Highlander Roofing & Construction

## I. Geographic Targeting Architecture

### Service Area Definition
- **Primary Market:** Macon County (Franklin HQ) + Jackson County (Sylva office)
- **Secondary Market:** Swain, Haywood, Transylvania, Henderson, Buncombe (western edge)
- **Tertiary Market:** Clay, Cherokee, Graham — served but not actively targeted with pages

### Page Hierarchy
```
/service-areas                          → Regional hub (all WNC)
/service-areas/franklin-nc              → Primary town page
/service-areas/sylva-nc                 → Primary town page
/service-areas/waynesville-nc           → Secondary town page
/service-areas/brevard-nc               → Secondary town page
/service-areas/highlands-nc             → Secondary town page
/service-areas/cashiers-nc              → Secondary town page
/service-areas/bryson-city-nc           → Secondary town page
/service-areas/cullowhee-nc             → Secondary town page
```

### Service × Location Matrix
Don't create separate pages for every service+town combo. Instead:

**Tier 1 Towns (Franklin, Sylva):** Deserve dedicated service+town content blocks WITHIN the town page. Rich enough for standalone indexing.

**Tier 2 Towns (Waynesville, Brevard, Highlands, etc.):** Town page with service mentions + internal links to main service pages. No separate /waynesville/roof-replacement pages.

**Tier 3 Towns:** Listed on Service Areas hub with "We serve [town]" + link to nearest Tier 1/2 page.

**Why:** Prevents thin content duplication. A "/highlands-nc/asphalt-shingles" page with 200 words of rewritten service copy hurts more than it helps.

## II. Town Page Design (Anti-Thin Framework)

### Required Content Blocks (minimum 800 words unique per page)
1. **Local Hero** — Photo of actual work in that town (or nearby), town name in H1
2. **Town Context** — 150+ words about the town's architecture, climate challenges, common home styles
   - NOT: "Franklin is a beautiful town in WNC" (generic filler)
   - YES: "Franklin's mix of 1960s ranch homes and newer mountain construction means roofing needs range from aging 3-tab replacements to premium architectural shingle installations on steep-slope designs"
3. **Services Available** — Cards linking to main service pages, with town-specific context
   - "Roof replacement in Franklin" links to /services/roof-replacement with anchor text
4. **Local Projects** — 2–3 project cards from that town/county (pulled from project data)
   - If no projects yet: "Recent work in [county]" with nearest examples
5. **Local Testimonial** — Review from a homeowner in that town or county
6. **Weather/Climate Block** — Town-specific weather data relevant to roofing/construction
   - Elevation, average rainfall, snow load zone, wind exposure
   - "At 3,500 feet, Sylva homes face heavier snow loads than valley properties"
7. **Service Area Context** — How Highlander serves this area (drive time from office, crew availability)
8. **CTA** — "Get a Quote in [Town]" with trust line
9. **FAQ** — 3–4 town-specific questions
   - "Do you serve homes outside Franklin city limits?"
   - "How does elevation affect roofing material choice in Highlands?"

### Anti-Thin Rules
- ❌ Never copy service page content into town pages (Google detects this)
- ❌ Never use the same 3 paragraphs with town name swapped
- ❌ No town pages without at least 1 real local photo
- ❌ No town pages for areas with zero completed projects (wait until you have proof)
- ✅ Each town page must have unique climate/architecture/local context
- ✅ Each town page links to 3+ service pages and 1+ project pages
- ✅ Each town page has unique FAQ content

## III. Internal Linking Network

### Hub-Spoke Model
```
Service Areas Hub ←→ Town Pages ←→ Service Pages
                                  ↕
                            Project Pages
                                  ↕
                            Blog Articles (local content)
```

### Linking Rules
1. **Every town page** links to: Service Areas hub, 3+ service pages, 1+ project pages, 1+ blog article
2. **Every service page** links to: 2–3 relevant town pages ("Available in Franklin, Sylva, and across WNC")
3. **Every project page** links to: the service type page + the town page where the project was completed
4. **Blog articles** with local topics link to: relevant town page + service page
5. **Homepage TownGrid** links to all Tier 1 and Tier 2 town pages
6. **Footer** includes top 6 town links

### Anchor Text Variation
- Primary: "roofing in Franklin, NC" / "Franklin roof replacement"
- Secondary: "our Franklin team" / "serving the Franklin area"
- Tertiary: "Learn more about our work in Franklin"
- Never: exact-match anchor text more than 2× per page

## IV. Regional Relevance Content Strategy

### "Built for WNC" Messaging
Every page should contain at least one WNC-relevant signal:
- Climate reference (elevation, rainfall, snow, UV exposure)
- Local building code reference
- Mountain architecture mention (steep slopes, exposed ridgelines)
- County/town name naturally mentioned
- Local landmark or geographic reference

### Regional Content Types
1. **Seasonal advisories** — "Preparing Your WNC Roof for Winter" (blog)
2. **Local material guides** — "Best Roofing Materials for Blue Ridge Elevations" (blog)
3. **Storm response** — "After the Storm: WNC Homeowner's Guide" (Storm Center)
4. **Town spotlights** — "Roofing Trends in Highlands, NC" (blog)
5. **Local project stories** — "How We Rebuilt This 1940s Franklin Farmhouse Roof" (project detail)

## VI. Review Strategy Integration

### Collection Triggers
1. **Post-project completion** — email with direct Google review link (24–48 hours after final walkthrough)
2. **Post-inspection** — if inspection-only (no project), request review for the inspection experience
3. **Milestone moments** — after year-1 warranty check-in, request updated review

### Review Content Guidance (suggest to customers)
- Mention the specific service (roof replacement, addition, etc.)
- Mention the town/area
- Mention the team member name if possible
- "We replaced our roof in Franklin with Highlander..." = perfect local SEO signal

### On-Site Review Display
- **Homepage:** Star rating + review count in TrustStrip
- **Reviews page:** Full reviews with town attribution
- **Service pages:** 1–2 relevant reviews (roofing reviews on roofing pages)
- **Town pages:** Reviews from that town/county
- **Schema:** AggregateRating on homepage + service pages (only if reviews are genuine and verifiable)

### Review Response Protocol
- Respond to every review within 48 hours
- Positive: Thank by name, reference the project type and town
- Negative: Acknowledge, offer offline resolution, never argue publicly
- Response signals engagement to Google's algorithm
