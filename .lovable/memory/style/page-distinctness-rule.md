# Page Distinctness Rule

Every page on the site MUST feel:

## 1. Personalized
- Tailor hero copy, imagery, and CTAs to the page's specific audience and intent
- Use division-aware theming (roofing = green accents, construction = gold accents)
- Adjust tone: homeowner pages are warmer; commercial pages are more authoritative

## 2. Visually Rich
- Minimum visual elements per page: hero with imagery, at least one stat/proof section, contextual testimonial, and a unique content block
- No page should have fewer than 5 distinct visual sections
- Use varied section backgrounds (light, dark, tartan-dark, heritage-bar dividers) to create rhythm
- Every page gets at least one premium component (QuoteModule, StatBar, ImageFrame, TestimonialCard)

## 3. Locally Relevant
- Reference WNC geography, climate, or community where natural
- Town pages must mention elevation, weather patterns, and local architecture
- Service pages must connect the service to mountain-specific challenges (wind, moisture, slope)

## 4. Distinct in Purpose
- Each page has ONE clear conversion goal — never ambiguous
- Section order must reflect the page's unique funnel stage (awareness → consideration → decision)
- No two service pages should share the same hero layout, section order, or CTA sequence
- Vary component variants across pages (e.g., testimonial: featured on service pages, compact on town pages)

## Anti-Patterns (NEVER do)
- Copy-paste a page layout and only swap text/images
- Use the same hero style on more than 3 pages
- Leave a page with only text content and no visual proof
- Use generic stock-feeling sections without local context
- Have two pages that could be confused for each other at a glance
