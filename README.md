# Mountain Peak Performance

You are a senior UX/UI designer, CRO strategist, and SEO architect.

We are redesigning https://www.highlandernc.com/

The goal is NOT to redesign it visually only.

The goal is to create an ULTRA-PERFORMANCE, HIGH-CONVERTING, MODERN roofing website that:

• Feels premium and authoritative

• Converts more visitors into booked inspections

• Supports SEO town expansion

• Supports paid ads landing traffic

• Integrates social proof and trust

• Is mobile-first

• Preserves brand logos, services, and core identity

We are keeping:

• Company name

• Logos

• Certifications

• Service list

• Service areas

• Core brand tone (local, trustworthy, established)

We are upgrading:

• Layout

• Messaging clarity

• Conversion architecture

• Visual hierarchy

• Internal linking

• Speed and performance

• Authority positioning

---------------------------------------

PRIMARY OBJECTIVE

---------------------------------------

Turn this into a “market leader” roofing website for Western North Carolina.

The new website should feel:

• Clean

• Modern

• Structured

• High trust

• Confident

• Regionally dominant

• Built for scale

---------------------------------------

UX/UI REQUIREMENTS

---------------------------------------

1. MOBILE-FIRST DESIGN (critical)

Most roofing traffic is mobile.

Buttons must be thumb-friendly.

Call CTA must be persistent.

2. HERO SECTION (Homepage)

Above the fold must include:

• Strong benefit headline (not generic)

• Subheadline focused on service area

• Primary CTA: “Request Inspection”

• Secondary CTA: “Call Now”

• Trust strip: Licensed / Insured / Warranty / Financing

• Background: High-quality roof imagery (mountain homes aesthetic)

3. HOMEPAGE STRUCTURE (Section Order)

A. Hero (conversion first)

B. Trust + Credentials row

C. Before/After gallery slider

D. Core Services Grid

E. “Serving Western NC” interactive town grid

F. Why Choose Us (3–4 proof pillars)

G. Reviews (Google embedded style)

H. Commercial Services Preview

I. Instagram feed preview

J. Strong CTA block

K. Footer with structured SEO town links

---------------------------------------

SEO ARCHITECTURE

---------------------------------------

We are building for town + service dominance.

Structure must support:

/services/roof-repair/

/services/roof-replacement/

/services/storm-damage/

/services/metal-roofing/

/commercial-roofing/

/commercial-maintenance/

/service-areas/

/service-areas/highlands-nc/

/service-areas/cashiers-nc/

/service-areas/franklin-nc/

/service-areas/sylva-nc/

(and additional priority towns)

Each town page must:

• Be unique

• Have local proof

• Have service breakdown

• Include internal links to core service pages

• Include strong CTA

• Be SEO optimized but not spammy

Internal linking must be intentional:

Service pages link to towns

Town pages link to services

Blogs link to both

---------------------------------------

CONVERSION ARCHITECTURE

---------------------------------------

We are designing for:

Visitor → Call or Inspection Request → Booked Inspection

Implement:

• Sticky mobile call button

• Sticky “Request Inspection” button

• Short form (Name, Phone, Town, Roof Issue)

• Fast response message: “We respond within X hours”

• Financing mention

• Insurance/storm documentation support

Every page must have:

• CTA above fold

• CTA mid-page

• CTA bottom-page

---------------------------------------

MESSAGING FRAMEWORK

---------------------------------------

Rewrite messaging to be:

Clear

Confident

Non-marketer language

Owner-focused

Avoid generic phrases like:

“High quality roofing services”

Use instead:

“Roof inspections across Highlands, Cashiers, Franklin & surrounding Western NC communities.”

Focus messaging on:

• Fast response

• Storm expertise

• Mountain climate knowledge

• Maintenance prevention

• Local presence

---------------------------------------

SOCIAL INTEGRATION

---------------------------------------

Add Instagram feed preview section.

Create a 3x3 mock grid structure:

Row 1: Before/After | Crew Photo | Roof Tip

Row 2: Reel Cover | Material Detail | Inspection Process

Row 3: Community Spotlight | Storm Checklist | Project in [Town]

Must look active and modern.

---------------------------------------

COMMERCIAL SECTION

---------------------------------------

Commercial must feel separate and professional.

Create:

• Commercial hub page

• Maintenance program page

• Inspection page

• Emergency repair page

Add:

• Facility / Property Manager messaging

• Site walk CTA

• Maintenance proposal CTA

---------------------------------------

VISUAL STYLE DIRECTION

---------------------------------------

Keep green brand tone but modernize it.

Use:

• More whitespace

• Strong typography hierarchy

• Cleaner icon system

• Strong section separation

• Dark + light contrast blocks

• Premium mountain aesthetic photography

The current site feels outdated and text-heavy.

The new site must feel structured, intentional, premium.

PERFORMANCE STACK

---------------------------------------

Recommend implementation for:

• GA4

DELIVERABLES REQUIRED

---------------------------------------

The redesigned website should:
